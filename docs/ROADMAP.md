# Roadmap

**Проект:** Project Artifact  
**Версия:** 0.1  
**Статус:** предварительный план

Сроки не назначаются до оценки объёма и создания первого прототипа.

## Этап 0. Концепция и документация

- [ ] Согласовать GDD с обоими участниками проекта.
- [ ] Проработать биографии и мотивацию трёх героев.
- [ ] Разработать историю артефакта и правила его действия.
- [ ] Составить предварительную хронологию событий.
- [ ] Определить структуру вступительных глав.
- [ ] Спроектировать последовательность общих локаций.
- [ ] Сформировать варианты финала, не выбирая канонический преждевременно.
- [ ] Подготовить художественное руководство.
- [ ] Уточнить технические требования PC и Android.

**Результат:** согласованная концепция, достаточная для прототипирования.

## Этап 1. Технический выбор и базовый прототип

- [ ] Проверить Godot 4 как основной кандидат.
- [ ] Создать пустой проект и настроить контроль версий.
- [ ] Реализовать тестовое перемещение персонажа.
- [ ] Проверить изометрическую сцену.
- [ ] Проверить платформенный участок с видом сбоку.
- [ ] Проверить переключение камер и режимов.
- [ ] Проверить управление на PC.
- [ ] Сделать раннюю проверку сенсорного управления Android.

**Результат:** технический прототип, подтверждающий пригодность движка и базового подхода.

## Этап 2. Прототип персонажей

- [ ] Реализовать базовое перемещение Воина.
- [ ] Реализовать базовое перемещение Вора.
- [ ] Реализовать базовое перемещение Мага.
- [ ] Проверить уникальные способности каждого героя.
- [ ] Проверить взаимодействие способностей с одними и теми же объектами.
- [ ] Проверить базовые боевые механики трёх персонажей.

**Результат:** три управляемых персонажа с различимым игровым поведением.

## Этап 3. Система общих локаций и состояния мира

- [ ] Реализовать интерактивные объекты с идентификаторами и состояниями.
- [ ] Реализовать сценарные фазы прохождения: Вор → Воин → Маг.
- [ ] Реализовать передачу изменений окружения между фазами.
- [ ] Реализовать проверки хронологии и доступности объектов.
- [ ] Исключить блокирующие прохождение состояния.
- [ ] Реализовать сохранение и восстановление состояния локации.

**Результат:** одна тестовая общая локация, которую три героя проходят по очереди, каждый своим способом.

## Этап 4. Вертикальный срез

Создать небольшую законченную часть игры, демонстрирующую ключевой игровой опыт.

Желательно включить:
- вступительный фрагмент хотя бы одной самостоятельной сюжетной линии;
- одну общую локацию с последовательным прохождением Вор → Воин → Маг;
- уникальные способности и базовый бой каждого героя;
- несколько головоломок и интерактивных объектов;
- обычных противников и одного босса либо особого противника;
- сюжетные сцены;
- сохранение и загрузку;
- тестовые сборки Windows и проверку Android.

**Критерий готовности:** игрок понимает различия героев, а последовательное прохождение общей локации ощущается осмысленной центральной механикой, а не повторением одного уровня.

## Этап 5. Производство контента

- [ ] Реализовать остальные индивидуальные главы.
- [ ] Реализовать остальные общие локации.
- [ ] Добавить эпизоды пересечения сюжетных линий.
- [ ] Реализовать противников и боссов.
- [ ] Добавить прогрессию и предметы.
- [ ] Добавить транспорт и специальные сцены, если они подтвердятся дизайном.
- [ ] Реализовать сюжетные события и диалоги.
- [ ] Создать финальную графику, анимации, эффекты и звук.

**Результат:** полный игровой контент.

## Этап 6. Балансировка и полировка

- [ ] Проверить сложность каждого героя.
- [ ] Проверить темп и продолжительность кампании.
- [ ] Проверить обязательные переходы между фазами общих локаций.
- [ ] Проверить сохранения на разных этапах прохождения.
- [ ] Проверить управление на разных устройствах.
- [ ] Оптимизировать производительность PC и Android.
- [ ] Провести тестирование и исправить критические ошибки.

## Этап 7. Подготовка релиза

- [ ] Подготовить сборку Windows.
- [ ] Подготовить сборку Android.
- [ ] Подготовить настройки графики и управления.
- [ ] Подготовить страницу проекта и материалы.
- [ ] Определить формат распространения и лицензионные вопросы.
- [ ] Выпустить тестовую версию.
- [ ] Собрать обратную связь и подготовить релиз.

## Критические контрольные точки

| Контрольная точка | Условие готовности |
|---|---|
| Прототип движения | Персонажи управляются, камера и коллизии работают |
| Прототип персонажей | У героев есть различимые способности |
| Прототип общей локации | Вор, Воин и Маг проходят один путь по порядку |
| Состояние мира | Изменения одного этапа корректно видны следующему |
| Вертикальный срез | Есть законченный игровой фрагмент на PC и проверка Android |
| Полная версия | Все сюжетные линии и обязательные главы проходимы |
| Релизная версия | Нет блокирующих ошибок, сохранения и управление проверены |

## Правило изменения плана

Новые идеи сначала фиксируются как предложения. Если они меняют основную структуру кампании, порядок прохождения, сюжетные мотивы или техническую архитектуру, изменения согласуются и затем отражаются в GDD и этой дорожной карте.
