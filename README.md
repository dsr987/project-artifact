# Project Artifact

Однопользовательская 2D-приключенческая игра в жанре экшен-платформера с изометрическими локациями, детализированным pixel art и тремя самостоятельными сюжетными линиями.

Игрок проходит истории Воина, Вора-ассасина и Мага. В начале герои не знают друг о друге; впервые они встречаются в хранилище артефакта. В общих локациях каждый герой последовательно проходит один и тот же путь своим способом: сначала Вор, затем Воин, затем Маг.

**Целевые платформы:** Windows PC и Android.  
**Целевая продолжительность:** 5–10 часов.  
**Движок:** Godot 4 рассматривается как предварительный кандидат; решение не утверждено.
